Vitruvius · De architectura · Book III · Chapter 5

One column,
read into being

Chapter 5 is a set of instructions. Every underlined phrase is a measure, and each one is tied to the stone it sizes. Read down the page and the column is built in the order Vitruvius gives it.

    Text: M. H. Morgan, Vitruvius: The Ten Books on Architecture, Harvard University Press, 1914, pp. 90–97 (public domain). The column is drawn for the one case the chapter states in full: eustyle, 25 Roman feet high. Interactive Architectural Edition by PhD Poturak Semir.
